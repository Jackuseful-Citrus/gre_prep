GRE 随身学习 · Windows / Linux 网页版

1. 打开
用 Chrome 或 Edge 打开 GRE-start.html，选择「阅间 综合训练」。也可直接打开 gre-reading-studio/dist/index.html。
两种系统使用同一份 HTML/CSS/JavaScript，不需要独立可执行程序、Python、Node 或启动服务。
保留整个 GRE 资料目录结构，PDF 和题图需要相邻的资料文件。无需重新解压旧压缩包。
Windows 的 .cmd 和 Linux 的 .sh 只是可选的浏览器打开入口；直接打开 HTML 即可。

2. 阅间自动保存
首次在底部点击「选择进度文件夹」，选择 U 盘的 gre-reading-studio/user-data 并允许读写。
网页会读取并恢复该目录已有的进度。之后会自动保存，也可以随时点击「保存进度」。
不用手动导出文件，不用输入文件名。主文件为 progress.json，上一份快照为 progress.previous.json。
内容包括综合答题历史、收藏、生词与 AI 联想、笔记、作文、训练会话、原阅读记录、模考及网页导入的题库。
拔盘前点击「保存进度」，等待显示已保存，再关闭页面并安全弹出 U 盘。
看到未授权、断开、空间不足或冲突提示时，按提示处理后重新保存。

3. 换电脑继续
在另一台 Windows 或 Linux 电脑上用 Chrome 或 Edge 打开 U 盘里的同一份网页。
选择同一个 user-data 文件夹，网页会自动读取和恢复，无需手动导入 JSON。
浏览器独立管理目录权限；换电脑、浏览器、盘符，或者重新打开后，可能需要重新选择目录或点击「授权保存」。
没有选择或授权目录时，记录仅保留在当前浏览器，不能自动带到另一台电脑。
为了直接写入 U 盘，请使用支持目录读写的 Chrome 或 Edge。Firefox 仍可离线练习，但不支持这套文件夹自动保存。

4. 网页内 OpenAI API Key
在阅间「生词本」输入 API Key，点击「启用词汇匹配」，即可生成近义词和形近易混词。
密钥只保留在当前页面内存中，刷新或关闭后需重新输入；不会保存到 U 盘或进度文件。
新匹配需要网络及可用 API 额度。已生成的结果随进度保存，可离线查看。

5. 词间 800 词卡
词间仍保持原功能：在「学习分析」导出、导入进度。阅间的新自动保存不包含词间的独立学习记录。
Linux 发音取决于系统和浏览器是否安装英语语音。

6. 验证范围
已在 Windows 的 Chrome / Edge 验证网页运行、保存模块、恢复与模拟 AI 请求。
当前环境没有 Linux 桌面，未进行 Linux 实机测试。网页使用相对资源路径和标准浏览器 API。
