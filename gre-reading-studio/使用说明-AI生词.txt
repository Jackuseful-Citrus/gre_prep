阅间 · API 设置、AI 生词、题目分析与自动保存

打开与配置
用 Chrome 或 Edge 打开 dist/index.html，进入「生词本」。Windows、Linux 都使用同一份网页，无需安装 Python、Node 或独立程序。
在 OpenAI API Key 输入框粘贴自己的密钥，点击「启用 API」。默认模型为 gpt-4.1-mini，也可填写支持 Responses 和结构化输出的模型。
首次分析或匹配会验证密钥和网络；API 额度、地区及项目权限由你的 OpenAI 账户决定。
如果原页面已打开，请刷新一次以载入新版。
API 面板右上角可「最小化 / 展开」，收起时保留状态提示，折叠状态会记住；尚未提交的输入不会因收起而丢失。

缺失答案与解析自动补充
默认开启「缺少答案或解析时自动分析（提交后）」。提交练习答案后，若原题缺少答案或逐题解析，会自动调用同一 API 配置。
支持综合练习与阅读专练；模考与练习成绩页仅在交卷并展开某一道题复盘时分析该题，不会提前显示答案或批量调用整卷。
答案与中文解题步骤显示在「AI 补充解析」，并随学习进度保存；已生成结果离线可看，刷新或重做时直接复用。
可以在题目下打开「API 设置」，关闭自动分析后仍可点「分析本题」。网络、额度或返回格式有问题时显示原因，点击「重试分析」重试。
AI 输出标为参考答案；原资料答案及正式正确率保留。若题干或必要图示不足，会说明缺失信息，不强行给出答案。
现有题库的题图已提供本地按需加载支持，直接打开网页也能传入 API，无需另外启动服务。请保留完整 dist/question-image-data 文件夹；后续自行导入的题图若无法读取，分析会明确说明缺失图示。

词汇联想
自动匹配新收藏和当前生词本页面上的未匹配词汇，展示原词中文释义、GRE 近义词、形近易混词及用法差别。
可以关闭自动匹配，再点「匹配此词」或「匹配本页生词」。相近词类型也可以切换为语义相关词。
同一模式下已有结果直接复用，已保存的结果可离线查看。生成失败可以重试，不影响原题答案和已有收藏。
AI 建议供学习参考，不代表 ETS 官方词频；近义词不一定可以在原句中直接互换。

密钥与网络
网页直接向 https://api.openai.com/v1/responses 请求，发送单词及原题语境，或当前题目、相关原文、选项及可读取题图，按你的 API 用量计费，使用 store:false。
密钥只在当前页面内存中保留，提交后清空输入框；不写入 localStorage、进度文件或 U 盘。刷新、关闭页面后需要重新输入。
学习、收藏和已生成结果的离线查看无需联网；生成新建议需要能访问 OpenAI API 的网络。
如果使用此前的本机桥接服务，新版仍兼容；日常使用直接打开网页即可。

自动保存与跨电脑使用
在底部点击「选择进度文件夹」，选择本应用的 user-data 文件夹并允许读写。推荐直接选择 U 盘上的该文件夹。
网页会先读取已有进度，再合并恢复；之后答题、笔记、生词、AI 结果和模考记录自动写入 progress.json。
「保存进度」立即写入同一文件，无需下载、导出或手动挑选文件名。progress.previous.json 保留上一份快照。
拔盘或关闭网页前点击「保存进度」，等待显示「已保存到所选进度文件夹」，然后安全弹出 U 盘。
换电脑后，打开 U 盘里的网页，选择同一个 user-data 文件夹。浏览器可能要求再次授权；这是读取 U 盘的浏览器权限。
若两页同时修改，网页提示冲突，点击「合并后保存」。写入失败会保留待保存状态，不会显示已保存。
Firefox 等没有目录写入 API 的浏览器可以离线练习；直接自动写入 U 盘请用 Chrome 或 Edge。
