阅间 · GRE 阅读

本地打开
双击本项目 dist 文件夹中的 index.html，用 Chrome 或 Edge 打开即可。
无需安装依赖、启动服务器或联网。请保留整个 dist 文件夹，data.js、app.js、styles.css 和 sources 目录需要与 index.html 在一起。

练习方法
1. 在阅读题库中选择主题、资料来源、题型与篇幅，可搜索文章或题干。
2. 点击文章的“开始阅读”，或选择篇数与计时后“随机开练”。
3. 左侧阅读文章，右侧选择答案。多选题需要选全；无法可靠映射的选句题可以输入原句。
4. 提交后查看原资料答案、原书解析及PDF出处。未提供答案、答案冲突或无法对应选项的题目不计自动正确率。
5. “这题我还不太确定”会保留到错题与不确定列表；重新确定答对后移出。收藏按文章保存。
6. 可以记录阅读笔记。学习记录页可导出和导入 JSON 备份。

本地记录
阅读进度使用独立的 localStorage 键 gre-reading-studio-progress-v1，与背词项目分开。
同一浏览器及同一打开地址可以保留进度。更换浏览器、移动文件或从本地切到在线版时，请先导出记录，再在新地址导入。
清除浏览器站点数据会清除本地记录。无法保存时页面会提示，仍可导出当前记录。
导入以较新的同题记录为准，合并收藏与练习历史，并保留已有笔记。

资料整理规则
从本地 PDF 及 ZIP/RAR 压缩包中提取阅读资料。
主题与题型使用关键词规则自动归类；难度仅展示资料原有标记。
只在文章、题干与选项的文字一致时合并；统一排版句号编号、引号和空白，不使用语义猜测匹配答案。
不同文字和选项的版本保留；同一道题的原资料答案有冲突时停止自动评分。
原书拼写、提取导致的词内空格等不作无依据改写。原始提取内容、页码、问题注记保留在 data 中，PDF保留在 dist/sources 中。
阅读方法及图片样题在“原始资料”中按主题打开原页，不计入可自动判分题数。
未混入填空、数学、写作或无独立阅读题组的长难句讲解。

工程结构
dist/index.html：网页结构
dist/styles.css：独立样式
dist/app.js：练习、记录与导入导出
dist/data.js：由已有提取数据构建的浏览器题库
dist/sources：阅读PDF与原资料附件
data：各来源结构化数据、来源清单、审计与原始提取内容
scripts：可复现提取及题库构建脚本
tests：来源完整性与交互验收

重新构建（需 Python，数据 JSON 已存在即可，无需重新提取）
python scripts/build_data.py
