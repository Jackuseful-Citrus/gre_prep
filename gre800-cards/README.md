# 词间 · GRE 800

一个直接在浏览器运行的中文 GRE 词卡应用。词库来自同目录上级的《GRE800词 》.pdf，包含原编号 001–800 的全部词条、815 个考法释义、8 个 List；保留原书 PDF 页码。

## 使用

- 自认模式：先显示英文单词，点击「认识」或「不认识」后直接揭晓正确释义和完整词条；「不认识」自动加入特殊待复习。答案页可直接改选，也能手动加入或移除。按 1 / 2 判断或改选，按 S 加入或移除，空格继续。
- 后退：自认模式和特殊列表复习均可点击「上一个单词」或按左方向键返回，完成页也能返回最后一个词。回看和改选不会丢失后续答案，刷新后仍可继续。误点「不认识」后改为「认识」，会撤销这次自动加入；原本已在列表里、后来手动加入或在另一轮再次确认不认识的词会保留。
- 特殊待复习：独立保存不认识和手动加入的词，可查看、移除，并用自认模式单独复习整个列表。完成复习后不会自动移除。自认结果单独保存，不计入四选一的正确率、掌握率或自动复习计划。
- 自认模式和特殊列表复习可分别续练；刷新或切换页面会保留当前单词与揭晓状态。进度 JSON 包含两个练习及特殊列表；导入合并按每个词的较新加入/移除操作处理，避免旧备份重新加入已移除的词。

直接用浏览器打开 `dist/index.html`。不需要安装依赖或构建；所有页面资源都在本地。也可以在本目录运行 `python -m http.server 8000 --directory dist` 后访问 `http://localhost:8000`。

- 基础模式：先看英文，选择认识、不认识或模糊。认识和模糊进入四选一，不认识直接显示答案。每轮不重复；到期词与易忘词优先，其余随机。
- 测试模式：选择 10、20、50、100 题，或输入 1–800 的任意整数。每题 1 分，直接查看答案记 0 分；最终按正确题数换算百分制得分。
- “认识”且答对算掌握；答错、不认识和“模糊但答对”进入待加强。支持复习本轮或全部待加强单词。
- 页面会将学习记录、当前词卡、未完成测试保存在当前浏览器的 localStorage。不同浏览器或不同地址之间不共享；清除浏览器数据会丢失记录。禁止存储时仍可学习，但页面会提示无法保存。
- 提示阶段按 1/2/3 选择认识/不认识/模糊；选择题按 1–4；答案页按空格继续。也可通过 Tab 和回车使用所有按钮。
- 发音使用浏览器内置语音服务，是否可用取决于浏览器和系统声音设置。

## 第二轮升级

- 完整词条：答案展示所有考法，包含原始中文释义、英文释义、例句、近义词和派生词；默认全部展开，可按考法或整体收起。缺失字段明确标为“原词表未提供”。
- 同义词训练：单词关联匹配、中文反向关联、异类词识别。只使用 `definitions.synonyms` 中能精确匹配现有 800 词的直接关系，保留考法来源。不进行对称/传递扩充，不把关联视为全部语境等价。异类题问的是“未列入该考法”，不宣称语义绝不相近。
- 反向回忆：中文→英文、英文释义→英文单词，保留熟悉程度流程；模糊但答对仍需复习。
- 间隔复习：新增 `nextReviewAt`、连续正确/连续确认次数、最近答错时间、复习次数与答错次数。认识且答对采用 1、3、7、14、30 天；不认识或答错 10 分钟；模糊答对 30 分钟。考试前 30 天内按剩余时间压缩周期，不超过目标日当天结束时间；已过的日期不继续压缩。
- 学习分析：8 个 List 掌握率，稳定掌握/待复习/未学习/到期数量，易忘词，14 天学习量和正确率图表与明细表。稳定掌握要求连续 3 次“认识且答对”且未到期。旧版掌握标记和累计次数保留；不会根据旧累计次数捏造历史趋势或连续正确次数。
- 进度导入导出：JSON，兼容 v1 原始状态及 v2 导出文件。导入前预览、校验与备份后合并。计数采用较大值，调度采用较新的记录；当前练习优先，重复导入不累加。独立设备的重复/新增作答不能仅靠汇总数据精确分辨，因此不会简单相加。
- TC、SE、RC 保留独立模块入口，当前不含未经核验的题目。

本次升级不修改 `words.js`、`words.json`、原始提取文本与原条目 JSON。疑点独立存放于 `lexicon.js` 的校核规则和审计报告；页面可查看释义/近义词等疑点。疑似关系不进入训练，原文仍可见。197 条直接关系通过当前规则；按词条去重后控制每轮数量，异类模式只有 3 个可用词条，不额外编造题目。

## 存储兼容

继续使用 `gre800-word-studio-v1` localStorage key，内部 schema 升为 `version: 2`。首次升级前原串另存为 `gre800-word-studio-v1-backup-v1`，不会重复覆盖；导入前另存为 `gre800-word-studio-v1-backup-before-import`。备份或写入失败时不覆盖原有进度，页面提示仅当前会话可用。

导出、导入都在浏览器本地完成，没有新增后端、账号服务或上传学习进度的请求。部署仍沿用原来的私人网页地址，因此同一浏览器原地址下的记录可以直接继续使用。

## 文件

- `dist/index.html`、`dist/styles.css`：页面与响应式排版。
- `dist/app.js`：交互、计分和学习进度。
- `dist/logic.js`：随机队列、选项和学习状态计算。
- `dist/lexicon.js`：按考法构建同义词关联、训练题与独立疑点标记。
- `dist/progress.js`：迁移、复习调度、分析和导入导出纯逻辑。
- `dist/views.js`：完整词条、分析、词库校核与 GRE 模块视图。
- `dist/words.js`、`dist/words.json`：从 PDF 提取的完整词库。
- `scripts/extract_vocab.py`：可复现的 PDF 提取脚本（需要 pypdf）。
- `scripts/extraction-report.json`：数量、连续编号、重复词与原文排版修正记录。
- `scripts/pdf-extracted.txt`、`scripts/raw-entries.json`：原始 PDF 提取内容；保留不改写。
- `scripts/audit-lexicon.cjs`、`scripts/lexicon-quality-report.json`：可复现的关联与疑点审计。
- `tests/logic.test.cjs`：核心逻辑和完整词库校验，使用 `node --test tests/logic.test.cjs` 运行。
- `tests/lexicon.test.cjs`、`tests/progress.test.cjs`、`tests/v2-data.test.cjs`：新增训练、迁移、调度、导入导出与原数据 SHA256 校验。可用 `node --test tests/*.test.cjs` 一起运行。
- `tests/v2-browser-qa.cjs`：真实浏览器功能测试，需要本地 Playwright Core 与 Chrome；不属于网站运行依赖。

发布内容仅包含 `dist/` 的静态资源。原始 PDF 不会作为网站文件发布。
